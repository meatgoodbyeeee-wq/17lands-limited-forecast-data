- **R/M(主表):見抜かれたカードで GRADE と実測の相関は高くない(差 ≈ 0、CI は ±0.2)**。|ずれ| は見抜かれた方が小さい(−0.69、CI は 0 を除く)が、符号付きずれは差なし。

## 4. 判定(PLAN.md の目安)
- R/M の名前正解率 30.4%(CI 22.5–38.8)→ **目安の「30% 以上」を機械的には満たす=「漏れは大きい」**。ただしぎりぎり(閾値を 0.4 ポイント超えただけ、CI は 30% をまたぐ)。
- 一方「見抜かれたカードで GRADE と実測の相関が有意に高い」は**成立しない**(R/M 差 −0.006 [−0.21, +0.20])。「|ずれ| が有意に小さい」は成立するが(上記の通り分布の違いで説明できそう)、「小さい」の条件(名前正解 10% 未満)は満たさない。
- 結論:**記憶による再認は大きい(R/M の 3 割が名前まで特定され、答えれば確実に当たる)が、その再認が GRADE の予測力を水増ししている証拠は見つからない(相関差 ≈ 0)**。目安に忠実に言えば「大」(境界)、実質的な GRADE への漏れは「検出できず(CI ±0.2 の範囲で、大きな相関の上乗せは否定的)」。

## 5. 注意
1. 本テストは「知識を使って思い出せ」と指示した上限寄りの測定。C9 は「過去の知識を使わない」と指示されており、実際の漏れはこれより小さい可能性がある(ただし指示で漠然とした記憶を抑えられる保証はない)。
2. 名前が言えなくても「強かった気がする」という漠然とした記憶は GRADE に効きうる。名前正解は漏れの下限寄りで、見抜かれなかった群にも漏れは混ざる。群間差が 0 でも漏れが無いとは言えない(両群とも漏れている場合、差は出ない)。この意味で、より直接的な検証は新セット(2025 年後半〜 2026 年、記憶が無い)と過去セットで B10 の精度を比べること(FRA/TRK の前向き検証)。
3. 28 セット中 2024 年以前は 19 セット。C9 の判定者が記憶していそうなセット(NEO、KHM、ONE、DSK、STX、AFR)では R/M の約半数が特定される。記憶が弱い 2025–26 年のセット(TLA 25%、TDM 17%、ECL 15%、EOE 8%、DFT・HOB・MSH・SOS・TMT は 0%)では漏れは小さい。LOSO の学習側には記憶ありセットが多いので、2025–26 年のセットでの精度は「記憶なし」の目安になる。
4. 1 回の呼び出し・1 サンプル(シード固定)。R/M 73 枚中の群比較で、CI は広い。FRA の再認 3 枚は再録で、基準線 0% に近い。
5. 回答者の CLI セッションにはプロジェクト名(sakiyomi)と 2 つのドキュメントのファイル名が見えていた(内容は不可)。カード名・正解は見えていない。
6. サンプルから複数セット再録カードを除外した。基本地形などテキスト無しカードも対象外。
