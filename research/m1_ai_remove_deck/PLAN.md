# M1: Forge の「AI には使いこなせない」印で、B10 の過大予測を減らせるか(事前登録 2026-10-30)

本番・main・Pages は変更しない。採用はユーザーが判断する。

## 背景(ユーザーの案)
Forge のカードの記述には、AI がうまく使えないカードに付ける印(`AI:RemoveDeck:All`。AI のデッキから除く)がある。
FRA では Omnipresence と Loyal Tutor に付いている。こうしたカードは人間にも使いにくく GIH が低いので、印を予測に使えば過大予測を減らせるのでは、という案。
FRA の 2 枚は、凍結 B10 がすでに最下位近く(下から 1.0〜1.7%)と予測し、17Lands の GIH も試合数不足で値がない。そのため FRA では効果を測れず、過去のセットで調べる。

## データ
- 予測: B10 の 1 セット抜きの予測 `../c9_power_questions/oof_B10.csv.gz`(28 セット、7,075 枚、actual_gih と pred)。
- 印: Card-Forge/forge の `forge-gui/res/cardsfolder` のカードの記述。
  - **主分析: セットの発売日の時点の印**。Forge の `forge-gui/res/editions` に書かれた発売日(Date)の終わり(UTC)までの最後のコミットの記述を使う。
    発売後のプレイを見て付けた印は、発売前の予測では使えないため。発売日の時点で記述がなかったカードは「印なし」とし、その枚数を報告する。
  - 報告のみ: 今日(基準のコミット)の時点の印。
  - 印 = `AI:RemoveDeck:All` を含む(古い形式 `SVar:RemAIDeck:True` も同じ扱い)。`AI:RemoveDeck:Random` は別に数え、報告のみ。
  - カード名の照合: 記述の `Name:` の行(両面・出来事などは表の面)と 17Lands の名前(`//` の前)を、英数字だけの小文字にして照合する。照合できない枚数を報告する。

## 指標
- 残差 r = 実測 − 予測(pp)。セットごとに平均を引く(セット全体のずれを除く)。
- 補正: 印のカードの予測から δ を引く。δ = **ほかの 27 セット**の印のカードの r の平均(1 セット抜き。そのセットの実測は使わない)。

## Rule M1(支持の条件。すべて満たす)
1. 28 セットの印のカード(主分析)の r の平均が負で、片側 p < 0.05(セット内で印を並べ替える検定、10,000 回)。
2. 補正後の全体の MAE が B10 より低い。
3. 補正後のセット内 Spearman の平均が B10 より低くない(下がらない)。
- 印のカードが合計 20 枚未満なら「判定できず」(効果があっても小さすぎて使えない)。

## 報告のみ
- 印のカードの枚数(セット別、レア度別)、r の平均と 95% 区間(セットを単位にしたブートストラップ)、今日の時点の印での同じ集計、`RemoveDeck:Random`。
- 補正で MAE が下がったセットの数。
- FRA: 凍結 B10 に同じ補正(δ は 28 セットの値)を当てた場合。FRA の 2 枚は採点の対象(GIH 500 試合以上)外なので、FRA の採点の数値は変わらない見込み。

## 既知の限界
- 印は Forge の開発者の判断で、付け方に一貫性はない。発売日より前に付いていても、発売前のプレビューの評判を反映している可能性はある。
- 照合できないカードや、発売日の時点で未実装のカードは「印なし」になる。
