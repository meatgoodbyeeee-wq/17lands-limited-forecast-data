## 内訳 (参考)
- 対象カード MAE: B10 3.240 → B13 3.240 / B13r 3.237。非対象はほぼ不変。pon 四分位でも差は 0.02 pp 未満。
- セット内上位15位 (実際) の AUC (対象カード): ev 0.725、c9 GRADE 0.759、B10 予測 0.800、B13r 0.805。ev は単体で GRADE より弱い。
- 名指しカード (予測 GIH WR %, 実際): Avengers Assemble! 64.5 → B10 52.7 / B13 52.8 / B13r 52.4;  Chronicle of Victory 64.0 → 53.7 / 53.8 / 54.7;  Necroduality 59.2 → 49.2 / 49.4 / 49.6;  Rite of the Dragoncaller 51.3 → 54.5 / 54.7 / 54.5;  Smile at Death 52.3 → 56.3 / 56.3 / 55.6。どれもほぼ動かない。

## 原因の見立て (事後)
- Avengers Assemble!: K=6, ON 8, OFF 2 と読まれたが、事前登録の λ = dwc + 0.5·iwc ≈ 4 で成立確率が 0.21 となり ev 3.3 (C9 GRADE 3.0 とほぼ同じ)。判定の質ではなく、成立確率の計算(λ の定義)が保守的すぎた可能性が高い。ただし λ の係数を結果を見て変えると事後調整になるため、本検証では変更しない。
- Rite / Smile / Necroduality は成立確率がごく低く、ev は低く出たが、実際 GIH WR 差はモデルに乗らなかった。ev の GRADE 相当値が既存の C9 情報に対して追加的でなかった。
