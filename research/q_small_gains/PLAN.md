研究のみ。本番モデル、公開中の予測、Pages は変えない。この計画は計算の前にコミットする。
基準モデルは B11g(公開中の TRK のモデル。`research/g3_retrain/oof_B11g.csv.gz`、28セット、7,075枚)。
FIN・MH3・FRA・TRK の実測は使わない。対象セットの人間の発売前評価も使わない。

セットの発売順(Q2・Q3 で使う):
KHM STX AFR MID VOW NEO SNC DMU BRO ONE MOM LTR WOE LCI MKM OTJ BLB DSK FDN DFT TDM EOE TLA ECL TMT SOS MSH HOB

## Q1 上位カードの物差し(探索的。採否には使わない)
問い: 「実測上位10枚を平均 4.6pp 低く予測している」(E1)のうち、どれだけが今の精度なら避けられない分か。
- 対象: B10、B11g、(B10 + B11g) / 2 の OOF。セットごとに計算し、28セットで平均する。
- セット内で、r = 予測と実測の相関、β = 予測を実測に回帰した傾き、D = 実測上位10枚の実測の平均(セット平均との差、pp)。
- 分解: 上位10枚の過小予測(中心化後)≒ (1 − β) × D。うち「避けられない分」= (1 − r²) × D(予測が偏りなく目盛りも合っている場合でも残る分)、「予測の縮みすぎの分」= (r² − β) × D。セット平均のずれは別に報告する。
- あわせて、次の物差しを各モデルで計算する: 予測上位10%のカードの平均の外れ(実測 − 予測)、実測上位10枚のうち予測上位20枚に入った枚数、実測を予測に回帰した傾き。

## Q2 前向き検証と、新しいセットへの重み(採否を決める)
問い: 新しいセットほど重くして学習すると、次のセットの予測は良くなるか。
- 対象セット: 発売順の最後の10セット(FDN DFT TDM EOE TLA ECL TMT SOS MSH HOB)。各対象について、それより前に発売されたセットだけで学習する(18〜27セット)。
- モデルは B11g と同じ(B5 の数値特徴量 + g3 + g3_z、ExtraTrees 600 + TF-IDF/Ridge、70:30、係数 1.25、シード3つの平均)。
- 腕: W0 = 重みなし。W8 = 重み 0.5^(a/8)。W4 = 重み 0.5^(a/4)。a は「対象セットの直前のセットを0として、何セット前か」。重みは ExtraTrees と Ridge の両方に `sample_weight` で渡す。中心 c は重みつきの平均。
- 実装の確認: 重みなしの関数で HOB を LOSO 予測し、`oof_B11g` の HOB と一致すること(最大差 1e-9 未満)。
- **規則 Q2**: 10セットで、MAE(Wk) ≤ MAE(W0) − 0.01pp、かつ セット内 Spearman の平均 ≥ W0 − 0.002、かつ MAE が W0 より小さいセットが 7/10 以上なら「支持」。W8 と W4 の両方が通ったら改善の大きいほうを報告する(2つ試したことを明記する)。
- 報告のみ: 同じ10セットでの LOSO の MAE と W0 の MAE の差(LOSO がどれだけ楽観的か)。
- 注意: G3 の教訓リストは BLB DFT DSK EOE FDN LCI MKM OTJ SOS TDM TLA の専門家評価から作ったので、g3 は完全には「前向き」ではない(実測は使っていない)。

## Q3 再録カードの過去実測(採否を決める)
問い: 同じ名前のカードが前のセットにあるとき、その実測で予測を直すと良くなるか。
- 再録カード: 同じ `name` のカードが、プール内のそれより前に発売されたセットにあるもの。基本土地は除く。
- 過去Δ = 直近の過去セットでの(実測 − そのセットの実測平均)(pp)。予測Δ = 対象セットでの(B11g の OOF 予測 − そのセットの予測の平均)(pp)。
- 補正: 予測' = 予測 + k × (過去Δ − 予測Δ)。k は、対象セット以外のセットの再録カードで、外れ(実測 − 予測、pp)を(過去Δ − 予測Δ)に回帰した傾き(切片なし)。セットごとに k を決め直す。
- **規則 Q3**: 再録カードの MAE が 0.10pp 以上小さくなり、かつ 28セット全体の MAE が悪化せず、かつ 再録カードが3枚以上あるセットの6割以上で再録カードの MAE が小さくなれば「支持」。
- 報告: 再録カードの枚数、k、レアリティ別、TRK 336枚のうちプールに同名カードがある枚数(TRK の実測は使わない)。
- 注意: OOF 予測は、同じカードが入った他のセットも学習に使っている。ここで測るのは、その上での上乗せ分。

## Q4 G3 のパス数の不一致(報告のみ)
問い: 学習は G3 が1パス、TRK の予測は3パス平均。この違いは予測を悪くしていないか。
- 対象: G3 が3パスある TMT と ECL(`research/g3_expert_grade/<SET>/pass{1,2,3}.json`)。FRA は特徴量の組み立てが別経路なので、今回は含めない。
- 各セットを LOSO(他の27セットは1パスの g3 で学習、B11g と同じ設定・シード)で予測する。対象セットの g3 を、pass1 / pass2 / pass3 / 3パス平均 の4通りに替える(g3_z はそのセット内で計算し直す)。
- 実装の確認: pass1 のときの予測が `oof_B11g` の TMT・ECL と一致すること(最大差 1e-9 未満)。
- 報告: MAE、セット内 Spearman、予測の SD、上位10%(実測)の MAE。
- 読み方(先に決めておく): 3パス平均が pass1 より2セットとも悪ければ、次のセットから1パスにする案を出す。そうでなければ今のままにする。2セットしかないので、採否の根拠にはしない。
