# L2′ 結果: 瞬速の非クリーチャー・パーマネントを自分のアップキープ/ドローで唱えないパッチ(集合 B、2026-10-19)

計画: PLAN_L2prime.md(結果を見る前にコミット済み)。集計: analyze_l2.py。結果: result_B.json。
コミットしたファイルだけで、結果が完全に再現することを確認済み。

## 実施内容
- 集合 B(seed 2、80 デッキ)を、パッチなし・パッチありで各 360 試合(10 デッキ × 8 グループの総当たり)。デッキと乱数の seed は同一。両者とも Default プロファイル。
- 実測の所要時間: パッチなし 約 19.5 分、パッチあり 約 19 分(合計 約 38.5 分)。ビルドは 42 秒。
- 打ち切り条件は発動せず: 時間切れはパッチなし 0 件・パッチあり 1 件。手札入りの記録は 1 プレイヤー 1 ゲームあたり平均 18.5 件(基準 8〜25)。

## 事前登録した判定: **効果あり**(ただし根拠は弱い。下の注意を必ず読むこと)

対象クラス T(スクリプトから機械的に決定): S.H.I.E.L.D. Flying Car、Stolen Stark Tech、Super Suit、Super Villain Lockup、Thunderbolts Conspiracy の 5 種類(集合 B のデッキのうち 35/80 に入っていた)。

## 注意(この結果をどう読むか)
1. **区間の下限が +0.7 ポイントで、判定は境界すれすれ**。標本は 5 種類のカード・約 150 カード×ゲーム。同じ実験をもう一度行って、区間が 0 をまたぐ可能性は十分ある。「効果あり」を、効果が確定したと読んではいけない。
2. **パッチの狙いどおりの効果ではない**。使用は「戦闘まで温存」ではなく、**自分のメイン1(14 → 68 件)と戦闘開始(14 → 33 件)に移った**。ブロック宣言以降の使用はほとんど増えていない。なぜ改善したのかは、この実験では説明できない。
3. カード別の差はばらつきが大きい(Super Suit 47% → 62%、Super Villain Lockup 52% → 67%、Stolen Stark Tech 47% → 45%、Thunderbolts Conspiracy 24% → 29%、Flying Car は n=6 で参考外)。平均を支えているのは Super Suit と Lockup。カード単位の結論は出せない。
4. 両者に同じパッチを当てているため、これは「両者がこの規則で動くとき、このカードの価値がどう測られるか」の差。デッキの質を揃えたランダムな構成での結果で、実際のドラフトデッキではない。
5. AA は集合 B のデッキに入っておらず、観測は 0 件。AA そのものへの効果は、この実験からは何も言えない。

## 探索的な照合(事前計画の外。参考)
実際の MSH の GIH WR(17lands、28日窓)で、T の 5 枚をまとめると **セット平均より 0.8 ポイント低い**(Flying Car +2.7、Lockup −0.7、Super Suit −1.4、Stolen Stark Tech −1.5、Thunderbolts Conspiracy −7.1)。
Forge の T は N に対して: パッチなし **−6.0 ポイント**、パッチあり **+0.3 ポイント**。**まとめた値では、パッチあり側のほうが実測(−0.8)に近い**。ただしカード別の順位は、パッチ前後とも実測と一致していない(5 枚で n が小さい)。この照合は事後に行ったもので、判定には使わない。
