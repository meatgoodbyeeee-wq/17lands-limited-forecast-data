# G1: C9 GRADE の系統的な誤りの診断(R/M カード)— 事前登録

Research only; 本番 gih-c3-28set-20260929 と Pages は変更しない。採用はユーザーだけが決める。トークン消費なし(既存の oof / 特徴量だけを使う)。計算前にこのファイルを書く。FRA は使わない。

## 目的
B10 で最も効いている C9 の GRADE(`c9_m_GRADE`、3パス平均)が、R/M のどの種類のカードを実測より低く(または高く)見ているかを特定する。引き継ぎメモの候補1。モデルは作らない。診断のみ。

## データ(すべて既存)
- `research/c9_power_questions/oof_B10.csv.gz`(set, name, rarity_ord, actual_gih, pred): 28セット、7,075枚。R/M = rarity_ord 2 または 3。
- `c9_features.csv.gz`(key = "SET|name" で結合、`c9_m_GRADE`)、`c5_atomic_effects/c5_features.csv.gz`(c5_* タグ)、`c9_power_questions/cards.csv.gz`(type_line, mv, colors を id 経由で結合)。
- 結合できない行は数を報告して除外する。

## 定義
- すべて「セット内で平均を引いた値」で扱う(セット間のオフセットを除く): `a` = actual_gih − セット平均、`p` = pred − セット平均、`g` = c9_m_GRADE − セット平均。単位は pp。
- GRADE の写像: R/M 全体で `a ~ g` の単回帰(傾き・切片)を1本だけ当てる(グループごとには当てない)。`gap` = a − 当てはめ値(GRADE から見た実測のずれ。正 = GRADE が低く見ている)。
- `res` = actual − pred(B10 の残差、セット平均補正後)。

## グループ(これ以外は見ない。後から追加しない)
1. C5 タグ: R/M で該当が15枚以上の c5_* 列(値 > 0 を該当とする)。
2. 主カードタイプ: type_line の「—」より前から Legendary / Artifact / Enchantment の修飾を除いた主タイプ(Creature, Instant, Sorcery, Planeswalker, Artifact, Enchantment, Land, その他)。
3. マナ総量: 0–2, 3–4, 5–6, 7+。
4. 色数: 無色, 単色, 多色。
5. レアリティ: R, M。

## 報告
各グループ(15枚以上)について n、`gap` の平均、`res` の平均、それぞれの標準誤差と t 値、セット別の符号一貫性(そのグループが3枚以上ある各セットで平均の符号が全体平均と同じセット数 / 該当セット数)。
- 判定基準(診断としての「系統的」): |t| ≥ 3(検定したグループ数を明記し、多重比較の目安とする)かつ 符号一貫性が該当セットの 65% 以上。両方を満たしたものだけを「系統的な誤り」と呼ぶ。満たさないものは「弱い兆候」として表に残すだけにする。
- 補足: GRADE の分布(R/M 内で GRADE が 3.0 以下なのに実測がセット内上位10%の枚数と、そのグループ構成)、Avengers Assemble!(MSH)の g、a、p、セット内順位。
- GRADE の誤りが B10 の最終残差にも残っているか(gap と res の相関、グループ別の res の平均)を併記し、「GRADE が低く見ているが B10 は他の特徴で補っている」グループを分ける。
