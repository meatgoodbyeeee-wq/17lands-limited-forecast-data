# TRK 影の予測(公開しない比較用の予測)— 事前登録 2026-11-10

研究のみ。公開中の TRK 予測(B11g、`gih-b11g-28set-20261029-trk`)、Pages、本番モデルは変えない。
この計画は、C9 の追加判定と予測の計算より前にコミットする。TRK の実測は見ていない(17Lands には作業環境からつながらない)。

## 目的
TRK を、FRA に続く2つ目の「実測を見る前に凍結した検証セット」にする。過去28セットは何度も検証に使っているため。

## 腕(すべて TRK 336枚、Pages の `data/trk/target.json.gz` sha256 8eb762b1…)
- **G(基準)**: 公開中の B11g。Pages の `data/trk/adopted-gih.json.gz`(sha256 11d763ac…)の `gih` をそのまま使う。
- **S**: G に広がり補正をかけたもの。S = m + 1.0738921258189766 × (G − m)。m は G の336枚の平均。係数は `research/g3_retrain/spread_b11g.json` の `b_all28`。トークン0。
- **T**: B10(C9 あり、広がり補正なし)。学習は本番と同じ28セット・同じシード(`c9.load_pool`、`e.predict`)。
  - TRK の C9 は、バッチ1〜3の192枚が 10/22〜26 に判定済み(Opus 3パス)。残りのバッチ4〜6の144枚を今日、同じルーブリック(`research/c9_power_questions/RUBRIC.md`、書き換えない)で Opus 3パス判定する。
  - 入力はバッチ4〜6の C3 入力と同じカード表示(カード名は「~」、セット・レアリティ・数値なし)。順序は p1 がそのまま、p2 が逆順、p3 がシャッフル(`random.Random(20261022 + batch)`、`trk_label.py` と同じ)。パスごとに別のエージェント・別のフォルダで判定し、他のパスを見せない。
  - C3〜C5 のラベルは公開版と同じ(Sonnet、`label/raw`)。
- **A(主の案)**: A = (T + G) / 2。

## なぜ B11h ではなく A か
- B11h(C9 と G3 を両方入れて学習)は 10/29 の診断用の案で、17セットの MAE は 2.308(B10 は 2.325、B11g は 2.330)。
- TRK の G3 判定(3パス)は `.gitignore` で除外されていて、リポジトリに無い。B11h を TRK に出すには G3 の再判定(約60万トークンと推測)が要り、公開中の B11g とも一致しなくなる。
- 代わりに、既存の OOF で (B10 + B11g) / 2 を計算した(2026-11-10、探索的、事前登録なし):17セットの MAE 2.303、Spearman 0.636、上位10%の MAE 3.95、B10 より良いセット 15/17、B11g より良いセット 14/17。28セットでは MAE 2.215(B11h は 2.219)。B11h と同等なので、G3 の再判定が要らない A を主の案にした。
- A は過去28セットの結果を見てから選んだ案。TRK が最初の汚れていない検証になる。

## 採点(TRK の実測が出てから、1回だけ)
- 実測: 17Lands の公開データ。集計は FRA と同じ `scripts/aggregate_17lands.py`(500試合以上のカード)。使ったデータの更新日を記録する。
- 指標: MAE(pp)、セット内 Spearman、実測上位10%の MAE、レアリティ別 MAE。
- **規則 TRK-A**: MAE(A) < MAE(G) かつ Spearman(A) ≥ Spearman(G) − 0.005 なら「支持」。
- **規則 TRK-S**: MAE(S) < MAE(G) かつ「予測上位10%のカードの平均の外れ(実測 − 予測)」の絶対値が G より小さければ「支持」。
- 報告のみ: T 単独、予測上位10%の偏り、実測上位10枚のうち予測上位20枚に入った枚数(G・S・T・A)。
- 検出力の限界: 過去28セットでは、A − G の MAE 差は平均 −0.023pp、1セットあたりの標準誤差は約 0.027pp。TRK 1セットでは向きが分かる程度で、採否は決まらない。「支持」なら過去セットの結果とあわせて次のセットへの採用提案を出し、決めるのはユーザー。「不支持」なら提案しない。
