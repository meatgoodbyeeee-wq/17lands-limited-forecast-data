# TP3:top player の GIH WR の「上手い人補正」— 事前登録(2026-11-13)

計算の前にコミットする。ユーザーの了承(2026-11-13「進めて」)による。設計は Fable 5.2。
公開中の予測、サイト、本番モデルは変えない。採用を決めるのはユーザー。

## 目的
top player(そのセットでの勝率帯 0.60 以上、50 試合以上。符号 top60n50)の GIH WR を発売前に予測する。予測は2つの部品に分ける。
- 土台:全体の GIH WR の発売前予測(B11g / B10)を、top の尺度に直したもの。
- 上手い人補正:カードの色・タイプ・効果タグから予測する、カードごとの上乗せ。

この検証は「上手い人補正が、学習に使っていないセットでも当たるか」を確かめる。

## 正直に書いておくこと(この計画の限界)
- 補正に使う項目は、過去 23 セットすべてを見た探索(`research/top_player/effects/`、2026-11-13)で選んだ。したがって、同じ 23 セットでの LOSO(第1段階)は、汚れていない検証ではない。
- 探索の中で、似たモデルの LOSO の成績をすでに見ている。タグのある土地以外のカードで、本物の差の分散のうち説明できた割合は、色・タイプ・レアリティ・マナ総量で 0.32、C5 を足して 0.35、C5 と C4 を足して 0.37 だった。
- 第1段階の役割は、手順を固定することと、手順が壊れていないことの確認。汚れていない検証は、第2段階の FRA と TRK(top の実測をまだ誰も集計していない)。

## データと定義
- 過去 23 セット(NEO〜HOB)。`research/top_player/effects/build.py` が作るカード表を使う(入力は `research/top_player/skill_compare/data/`)。
- 対象カード:top の GIH の試合が 500 以上、top 以外の全員の試合も 500 以上。
- top だけの差 r:セット内で中心化した top の GIH から、top 以外の全員の GIH(同じく中心化)に傾き b を掛けた値を引いた残り(pp)。b はセットごとに実測で当てはめる。r は実測だけで決まり、予測に依存しない。
- 本物の差の分散 τ²:試合を draft_id で 2 分した独立な半分どうしの r の共分散。
- カードの重み:1 / (r の標本分散 + τ²)。τ² は学習側のセットだけで計算する。
- 効果タグ:C5(`research/c5_atomic_effects/c5_features.csv.gz`)、C4(`research/c4_fine_effects/c4_features.csv.gz`)、本文とタイプ(`research/c14_context_power/set_cards.csv.gz`)。カード名は「 // 」の前で切って合わせる。
- タグの無いカード(ボーナスシートなど)と土地は、補正 0 とする。

## 腕(比べる予測)
補正(学習側のタグつき・土地以外のカードで、重みつき最小二乗。切片あり):
- **TP3(主)**:ユーザーが了承した 14 項目。青、緑、クリーチャー、インスタント、ソーサリー、繰り返し使えるマナ加速(c5_RM > 0)、色マナの補助・土地サーチ(c5_FX > 0)、ルーター・自分の手札を捨てる効果(本文の一致。`build.py` の x_loot または x_discard_self と同じ正規表現)、墓地からの回収が主(c5_RC ≥ 2)、墓地からの再利用が主(c5_RE ≥ 2)、装備品・オーラの修整(c5_EQ > 0)、速攻が主(c5_HS ≥ 2)、破壊不能・呪禁・護法(c5_IN > 0)、マナ総量 5 以上のクリーチャー。
- **TP3basic(比較)**:5 色、クリーチャー・インスタント・ソーサリー、レアリティ(4 段階)、マナ総量(0〜8 に丸める)。
- **TP3all(比較、項目を選ばない)**:TP3basic に、C5 の全タグ(強さ 0〜2)と RATE・CLK・BLK、C4 の 14 項目と役割を足す。標準化してリッジ回帰(λ = 300 で固定)。
- **入れ替え対照**:学習側の r をセット内で無作為に入れ替えて TP3 を学習する。20 回(シード 20261113〜20261132)。

予測した補正は、評価するセットの対象カードの中で平均 0 にそろえる。

土台(全体の予測は 28 セット LOSO の OOF。`research/g3_retrain/oof_B11g.csv.gz`、research/q-small-gains ブランチ):
- **TP0K(主)**:セット内で中心化した B11g の予測(pp)に k を掛ける。k は学習側のセットで、原点を通る最小二乗で決める。
- **TP0L(比較)**:B11g の予測をオッズに直して定数 c を足し、勝率に戻してから中心化する。c は学習側のカードの「logit(top の実測 GIH) − logit(全体の実測 GIH)」の平均。

## 第1段階:LOSO(23 セット。1 セットずつ除いて学習し、除いたセットを予測する)
物差し(除いたセットをすべて合わせて計算):
- 説明できた割合 = cov(補正, r)² / (var(補正) × τ²)。本物の差の分散のうち、補正で説明できた割合。r のぶれは補正と独立なので、この式で本物の差との相関の 2 乗になる。
- セットごとの相関(補正と r)が正のセット数。
- 較正の傾き(r を補正に回帰した傾き。1 なら大きさが合っている)。
- 土台との組み合わせ:top の GIH(セット内で中心化、B11g の OOF と名前が合ったカード)に対する MAE と順位相関。セット平均。

主の母集団は、対象カードすべて(タグの無いカードと土地は補正 0)。タグつき・土地以外に限った値も報告する。

規則:
- **S1(主)**:TP3 の説明できた割合が 0.15 以上、かつセットごとの相関が正のセットが 17/23 以上、かつ入れ替え対照 20 回の最大値を上回る → 「支持」。支持なら第2段階の凍結に進む。不支持なら凍結せず、ここで止める。
- **S2(報告のみ)**:TP3 と TP3basic・TP3all の説明できた割合を比べる。主の腕は結果によらず TP3(了承済みの項目)。TP3 が TP3basic より 0.03 以上低ければ、「絞った項目は、色・タイプ・レアリティ・マナ総量だけのモデルに劣る」と報告する。
- **S3(副)**:MAE(TP0K + TP3) < MAE(TP0K)、かつ 14/23 セット以上で改善 → 「MAE でも支持」。補正を完全に当てても MAE の改善は 0.03〜0.04pp(計算上)なので、S3 の不支持だけでは S1 を覆さない。
- **B(報告のみ)**:TP0K と TP0L の MAE・順位相関。主の土台は TP0K。

## 第2段階:FRA と TRK の予測を凍結し、実測で 1 回だけ採点する(S1 が支持のときだけ)
凍結:
- 補正の式は、23 セットすべてで学習し直す(TP3、TP3basic、TP3all)。k と c も 23 セットで決める。
- FRA の土台は凍結済みの B10(`research/c9_power_questions/fra_frozen_predictions.csv` の pred_B10。k と c は `oof_B10` で決める)。TRK の土台は公開中の B11g(research/trk-shadow の `research/trk_shadow/trk_frozen.csv` の G。k と c は `oof_B11g` で決める)。
- FRA のタグは C5・C4 の表の FRA の行。TRK のタグは `research/trk_preview/label/` の C3〜C5 のラベル(research/trk-shadow ブランチ)。
- カードごとに、土台(K・L)、補正(3 つ)、主の予測(TP0K + TP3)を書き出し、sha256 を記録してコミットする。FRA・TRK の top の実測は、凍結のコミットより前には集計も取得もしない。

採点(セットごとに 1 回だけ。条件を変えたら「事後の変更」と書く):
- 実測:17Lands 公開データ(Premier Draft、最初のドラフトから 28 日間)を、23 セットと同じ集計(`scripts/skill_compare_aggregate.py` と同じ処理)にかける。対象カードと r の定義は上と同じ。
- **F1(主)**:TP3 の補正と r の Pearson 相関が正で、片側の並べ替え検定(10,000 回、シード 20261113)で p < 0.05 → 「支持」。見込みの相関は 0.15〜0.2(LOSO で説明できた割合が 0.2〜0.3 の場合の計算値)。
- **F2(副)**:top の GIH(セット内で中心化)に対する MAE で、TP0K + TP3 が TP0K より小さい。差と、カードの再標本化による 95% 区間を報告する。
- **F3(報告のみ)**:TP3basic・TP3all の同じ値、TP0K と TP0L の比較、順位相関。
- 28 日間の窓が閉じていない場合(窓の最後の日のドラフトが無い場合)は、その旨を書いて採点する。公開データに勝率帯の列が無い場合は採点できない。
- FRA は公開データがあるので、凍結の後すぐ採点する。TRK は公開データが出てから採点する。
