## カード単位の確認:上手い人だけの差は本物か(2026-11-11 追記、探索的)
ユーザーの指摘「top しか使いこなせないカードを誤差で丸め込んでいないか」を受けた確認。`card_level_skill.py`。
残差 e = top(中心化)− 0.830 × top 以外(中心化)。試合を draft_id で2分した半分どうしは独立なので、半分間の共分散が「本物の差」の分散になる。

- 本物の差の SD は 0.44pp(セットのブートストラップ 95% 区間 0.36〜0.51)。試合数の層(500〜1,999 / 2,000〜4,999 / 5,000 以上)で 0.45 / 0.42 / 0.43 と変わらない。観測された残差の分散の 14%。
- 二項分布からのぶれの見積もりは実測より 4% 大きかった(1.202 対 1.151)。この過大分が本物の差(0.19)を隠していた。
- 外れ値は偶然より多い。|z| > 3 が 82枚(偶然なら 15.6枚)、|z| > 4 が 10枚(0.36枚)。両方の半分で z > 1.5 が 77枚、z < −1.5 が 71枚(偶然ならそれぞれ 25.8枚)。逆向きは 27枚(偶然なら 51.6枚)。
- 両方の半分で同じ向きだった 148枚は、17Lands のサイトの Top でも同じ向き(上手い人が良い側 +0.82、悪い側 −0.81pp。試合を一部共有するので独立ではない)。
- 片方の半分で選んで、もう片方で読むと、差は約 15% 残る(z が 2〜3 の層で +3.07 → +0.48pp)。
