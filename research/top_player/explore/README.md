## 勝率帯のしきい値を変えた場合(2026-11-11 追記、探索的)
公開データの勝率帯は 0.02 刻みなので、65% ちょうどでは切れない。集計済みで一番近いのは 0.64 以上(`top64n50`)。0.66 以上は未集計。折半のデータが無いので、ぶれは二項分布の標準誤差で見積もった(0.60 以上では折半信頼性 0.883 に対して 0.878 で、ほぼ一致)。

| 項目(23セット平均、pp) | 0.56 以上 | 0.60 以上 | 0.64 以上 |
|---|---|---|---|
| 試合の割合 | – | 20.4% | 7.3% |
| 対象カード(500試合以上) | 6,142 | 5,780 | 4,509 |
| 水準の差(対 全体) | +5.72 | +8.40 | +11.52 |
| 傾き(対 全体、セット内で中心化) | 0.849 | 0.817 | 0.784 |
| 順位相関(対 全体) | 0.965 | 0.927 | 0.850 |
| 縮めた後の残差の SD / 測定のぶれの SD | 0.76 / 0.82 | 0.99 / 1.02 | 1.26 / 1.31 |
| 信頼性(二項分布から) | 0.929 | 0.878 | 0.763 |
| B11g × k の MAE(k) | 1.785(0.87) | 1.732(0.80) | 1.665(0.78) |
| 全体を完全に当てたときに残る MAE | 0.547 | 0.737 | 0.966 |

- 0.64 以上で順位相関が 0.850 に下がるのは、測定のぶれで説明できる(残差の SD 1.26 に対してぶれの SD 1.31)。
- 0.64 以上の対象カードは神話レアが 1.7%(0.60 以上では 6.0%)。試合数が足りず、レア・神話レアが落ちる。
- スクリプト:`threshold_sensitivity.py`
