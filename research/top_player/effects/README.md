# top と全体で差がつくカードの共通点:効果・能力別(2026-11-13、探索的)

事前登録なしの探索的な集計。採否には使わない。FRA と TRK は対象外。

- 差の定義:top(勝率帯 0.60 以上、50 試合以上)の GIH から、top 以外の全員の GIH で説明できる分(セットごとの一次式)を引いた残り(pp)。
- 対象:23 セット、効果タグのある土地以外のカード 4,977 枚(top の試合が 500 以上)。ボーナスシートなどタグの無い 493 枚と土地は除いた。
- 効果の分類:C5(効果タグ 62 種)、C4(14 項目と役割)、カードのタイプ行、本文の文字列一致。C5・C4 はカード名を伏せて本文だけから付けたタグ。
- 推定:試合数で重み付け。色・カードタイプ・レアリティ・マナ総量・セットをそろえた差。標準誤差はセット単位。237 項目を調べたので、偽発見率(q 値)を付けた。

| ファイル | 中身 |
|---|---|
| `build.py` | 差とタグを結合したカード表を作る |
| `analyze.py` | 項目ごとの差、段階別の値、まとめて入れたときの説明力、極端なカードの共通点 |
| `followup.py` | 引いたとき(IWD)とデッキ単位(GNS)、青の内と外、頑健性 |
| `joint.py` | 主な項目を同時に入れたモデル、タグの抜き取り確認 |
| `results/effects_all.csv` | 全 237 項目の結果 |
| `results/effects_iwd_gns.csv` | IWD と GNS を目的にした結果 |
| `results/joint.csv` | 同時に入れたモデルの係数 |
| `results/cards_est.csv.gz` | カードごとの差(縮めた推定値つき) |

主な数値は statsmodels の WLS(セット単位の頑健な標準誤差)で検算して一致(RM +0.348、EQ −0.271、HS2 −0.350、RC2 +0.267、CS −0.188、DR +0.015、青 +0.514)。
